# xz1220.github.io

Daniel Xing's personal site — projects and writing, at <https://xz1220.github.io>.

Astro 6 + Tailwind CSS 4, statically built, deployed to GitHub Pages by the
workflow in `.github/workflows/deploy.yml` on every push to `main`.

## Design

"Drafting table": engineering graph paper in the light theme, cyanotype
blueprint in the dark theme. Source Serif 4 for reading, Sometype Mono for
labels and chrome (self-hosted latin subsets in `src/assets/fonts/`; CJK falls
back to system serifs). Project covers are hand-drawn SVG "figure plates"
(`src/components/project/Plate*.astro`) — one per project, drawn as line-art
schematics. See `PRODUCT.md` for the full design brief.

## Develop

```sh
pnpm install
pnpm run dev       # local dev server
pnpm run build     # static build to dist/ (pagefind index runs as postbuild)
pnpm run preview   # serve the production build locally
pnpm run check     # astro check + biome
pnpm run format    # prettier
```

## Traffic analytics

Cloudflare Web Analytics is enabled when the build has a
`PUBLIC_CLOUDFLARE_WEB_ANALYTICS_TOKEN`. Until configured, analytics is disabled.

1. In [Cloudflare Web Analytics](https://dash.cloudflare.com/?to=/:account/web-analytics),
   add `xz1220.github.io` and choose manual JavaScript installation.
2. Copy the public `token` from **Manage site → JS snippet** (not an API key).
3. Add it as a GitHub repository **Actions variable** named
   `PUBLIC_CLOUDFLARE_WEB_ANALYTICS_TOKEN`, then rerun the deployment workflow.
4. Visit the blog and open its Cloudflare Web Analytics dashboard. Data can take
   a few minutes to appear; filter by Path to compare individual articles.

For local builds, copy `.env.example` to `.env` and fill in the token. The script
only runs on the production hostname, skips the dev server, and waits until a
prerendered page is activated. Removing the variable and redeploying disables it.
Stats begin after activation; historical visits cannot be recovered.

## Content

- Posts: `src/content/post/*.md` (frontmatter: title, description, publishDate, tags)
- Projects: `src/content/project/*.md` (adds repo/demo/featured/video fields)
- Adding a project? Give it a plate: add a `Plate<Name>.astro` next to the
  others and register its id in `src/components/project/Plate.astro`.
- The default OG card is generated by `scripts/generate-social-card.mjs`;
  per-post OG images are built at deploy time from `src/pages/og-image/`.
