# xz1220.github.io

「邢政的笔记」 — Daniel Xing's site, at <https://xz1220.github.io>.

Astro 6 with plain CSS, statically built, deployed to GitHub Pages by the workflow in
`.github/workflows/deploy.yml` on every push to `main` and once a day (to refresh the
作品 star counts).

## Design

「长文书房 The Book」 (committed 2026-10-22): the home page is a 目录 (contents page),
articles are chapters with sources as sidenotes in the margin, and the type is
Chinese-first — Noto Serif SC with Source Serif 4 for reading, 志莽行书 for the titles,
no italic CJK, phrase-aware line
breaks, 标点挤压, warm paper with a 夜读 dark mode. See `design.md` for the rules and
`PRODUCT.md` for the brief.

Webfonts are self-hosted: after `astro build`, `scripts/localize-fonts.mjs` downloads
only the font slices the pages use into `dist/fonts/` and rewrites the links, so no
page depends on Google Fonts. The build fails if that step fails.

## Develop

```sh
pnpm install
pnpm run dev       # local dev server (links Google Fonts directly)
pnpm run build     # static build to dist/ (postbuild self-hosts the fonts)
pnpm run preview   # serve the production build locally
pnpm run check     # astro check + biome
pnpm run format    # prettier
```

## Traffic analytics

Cloudflare Web Analytics is enabled when the build has a
`PUBLIC_CLOUDFLARE_WEB_ANALYTICS_TOKEN`. Until configured, analytics is disabled.

1. In [Cloudflare Web Analytics](https://dash.cloudflare.com/?to=/:account/web-analytics),
   add `xz1220.github.io` and choose manual JavaScript installation.
2. Copy the public `token` from **Manage site → JS snippet** (not an API key).
3. Add it as a GitHub repository **Actions variable** named
   `PUBLIC_CLOUDFLARE_WEB_ANALYTICS_TOKEN`, then rerun the deployment workflow.
4. Visit the blog and open its Cloudflare Web Analytics dashboard. Data can take
   a few minutes to appear; filter by Path to compare individual articles.

For local builds, copy `.env.example` to `.env` and fill in the token. The script
only runs on the production hostname, skips the dev server, and waits until a
prerendered page is activated. Removing the variable and redeploying disables it.
Stats begin after activation; historical visits cannot be recovered.

For article discovery, filter the dashboard by **Path** to compare posts and by
**Referer** to see traffic from search engines, Zhihu, or AI products that send
a referrer. Direct visits and clients that omit a referrer cannot be attributed
to a source. The production deployment already has the site token configured.

## Article discovery

Post pages expose a canonical URL, Open Graph metadata, and `BlogPosting`
structured data with the author, original publication date, revision date,
language, image, and optional Zhihu source. The source is also linked in the
article footer. The sitemap, robots.txt, and RSS feed include published posts.
When updating a post, keep its original `publishDate` and set `updatedDate` to
the date of the substantive revision. Set `sourceUrl` when migrating an article
from another site.

## Content

- Posts: `src/content/post/*.md`. Frontmatter: `title`, `description`, `publishDate`,
  `tags`; optional `deck`, `lang` (default `zh-CN`), `updatedDate`, `sourceUrl`,
  `coverImage`/`coverCredit`, `draft`, and:
  - `part`: `agent` (卷一 Agent 工程) or `career` (卷二 创业与职场). Chinese posts are
    numbered 01, 02 … by publish date; English posts go to 附 English.
  - `frontispiece: true`: show the cover as the 卷首图 (real artwork only);
    `coverInBody` hides a body image that repeats it.
- Citations: write them as footnotes (`…许多天。[^4]` and `[^4]: [Title](url)，Publisher。`);
  they render as sidenotes. An image followed by an italic line becomes a numbered figure.
- 作品: `src/data/works.ts` has the curated copy; only public repositories with at least
  10 stars are listed, using live star counts from the GitHub API at build time.
  `src/content/project/*.md` adds a page for a listed work.
- The default OG card is generated by `scripts/generate-social-card.mjs`;
  per-post OG images are built at deploy time from `src/pages/og-image/` for posts
  without a cover.
